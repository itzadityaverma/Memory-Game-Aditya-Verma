# Memory Game 🧠

A simple browser-based memory card matching game built using vanilla HTML, CSS, and JavaScript. No frameworks, no libraries — just pure frontend.

## How to Play

- Click any card to flip it and reveal the hidden emoji
- Click a second card to find its match
- Matching pairs stay open, non-matching pairs flip back
- Match all 8 pairs to win!
- Try to finish with the least moves and fastest time

## Features

- 4x4 grid with 8 emoji pairs
- Move counter and live timer
- Dark mode toggle (saves your preference)
- Win screen showing your final score
- Fully responsive — works on mobile and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

Just download the `index.html` file and open it in any browser. No installation needed.
