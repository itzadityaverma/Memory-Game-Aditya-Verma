A classic memory challenge. Flip tiles, find pairs, and beat your own record. Simple rules — surprisingly satisfying.

How to play

  1. Flip a tile by clicking on it to reveal a hidden icon.
  2. Find the pair — click a second tile to try and match it.
  3. If they match, both stay face-up. If not, they flip back.
  4. Match all 8 pairs to win the game!
  5. Try to finish with the fewest moves and fastest time.
